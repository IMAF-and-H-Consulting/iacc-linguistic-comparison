# IACC (Interagency Autism Coordinating Committee) — Publications Archive
Source: https://iacc.hhs.gov/publications/ (incl. archives). Downloaded 2026-09-15.
All files are the latest posted version of each document. INDEX.csv lists every file with its source URL.

Folders:
- strategic-plan/ — IACC Strategic Plan for ASD Research (2009-2013, 2017, 2019, 2023 + easy-read)
- summary-of-advances/ — annual Summary of Advances in ASD Research (2007-2023, + easy-read editions)
- report-to-congress/ — IACC/HHS Reports to Congress (2009, 2012, 2017, 2018, 2021, 2022, 2023)
- portfolio-analysis/ — ASD Research Portfolio Analysis reports (2008-2022, incl. At-a-Glance)
- international-portfolio-analysis/2016/ — international portfolio analysis
- publications-analysis/2012/ — IACC publications analysis
- autism/ — USPSTF-related report to Congress (2016)
- general/ — IACC letters & statements (wandering, seclusion/restraint, insurance coverage, GAO responses, UN resolution, NVAC letter)
