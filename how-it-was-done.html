01 · Source record

One archive, plus the working draft.

The comparison begins with the IACC’s public publication record and the July 2026 Strategic Plan working draft. The archive index preserves each publication’s source URL and local series classification.

Input

60 earlier IACC publications and one July 2026 working draft.

Transformation

Inventory the latest posted versions across strategic plans, annual summaries, reports to Congress, portfolio analyses, letters, and statements.

Output

A traceable document index with source URLs, years, series, variants, and file metadata.

02 · Corpus inventory

Define the comparison set before measuring.

The notebook inventories 61 documents. The analysis set contains 46 documents: eight earlier strategic plans, 37 other publications, and the draft. Fifteen inventoried items are excluded because they are under 2,000 words or are easy-read/at-a-glance editions.

Input

Archive files, the draft, and document metadata.

Transformation

Detect document variants and apply the same inclusion rules throughout the analysis.

Output

documents.csv, a corpus timeline, and stable document IDs used by later stages.

document inventorycorpus summary

03 · Extraction and cache

Extract once; reuse exactly what matches.

PyMuPDF is the primary PDF extractor, with pypdf, pdfplumber, and pdftotext as fallbacks. A content-addressed cache lets the notebook reproduce the analysis without the original PDFs.

Input

Source PDFs when present, otherwise the repository’s extracted-text cache.

Transformation

Hash each PDF with SHA-256. Reuse matching cached pages; re-extract a document if its bytes change while retaining valid cache entries for the rest.

Output

Page-level text, table-of-contents metadata, and a cache manifest keyed by content hash.

The shipped cache is what makes the one-click Colab route and a fresh local clone practical: the full analysis can run without downloading every source PDF again.

notebook sections 1–2cache manifest

04 · Shared cleaned corpus

Remove apparatus, not evidence.

Running headers and footers, tables of contents, and reference lists are removed before linguistic measurement. Citation density helps identify reference-list boundaries, and cleaning details are reported for the draft and earlier strategic plans.

Input

Page text and extraction metadata for every included document.

Transformation

Normalize ligatures and line breaks, detect repeated running lines, exclude contents pages, and identify trailing references.

Output

Consistent cleaned prose and document-level cleaning metadata shared by all measurement branches.

Using the same cleaned corpus is the crucial dependency: readability, vocabulary, similarity, reuse, and section comparisons are not calculated from different versions of the documents.

05 · Parallel measurements

Different questions, one cleaned text.

The notebook’s sections 3–10 calculate complementary views of the record. A supplementary script adds agency/community role analysis. Select a card to open the corresponding evidence.

Style + z-scoresSix readability formulas, sentence and word length, MATTR lexical diversity, passives, modality, hedges, boosters, nominalisation, and acronyms. Z-scores locate the draft against the earlier plans and broader record. Lexicon + subject referencesDomain terms, person-first and identity-first naming, ASD/autism usage, and one non-overlapping count of explicit references to autism or autistic people. Agency + community rolesDependency parsing classifies matched agency, autistic-person, and community mentions by agent and patient proto-roles. Visibility rates remain separate from role shares. KeynessWeighted log-odds with informative Dirichlet priors identify words and bigrams that are distinctive against earlier strategic plans and SP-2023 alone. Vocabulary turnoverNew terms used at least five times but absent from the earlier record, and dropped terms previously used across at least three strategic plans. Similarity + text reuseTF-IDF cosine similarity, Burrows’ Delta stylometry, and 8-word-shingle inheritance distinguish topical/style similarity from verbatim textual carryover. Longitudinal trendsSpearman correlations describe term movement through 2007–2023; pairwise plan comparisons measure how far each strategic plan moves from its predecessor. Reversal controlsWalk-forward controls refit trends on each document’s own past and trailing eight-year window, avoiding a future-fitted baseline for earlier documents. Draft sectionsThirty-seven outline sections of at least 300 words are profiled for readability, prescriptiveness, naming, novelty, and nearest earlier document.

08 · Publication build

Select a payload; ship one readable page.

build_explorer.py reads selected CSVs, converts their values into a curated JSON payload, replaces /*__PAYLOAD__*/null in explorer_template.html, and writes the self-contained index.html.

Input

Exported CSVs plus the explorer’s HTML, CSS, and browser code template.

Transformation

Round values for display, choose comparison series and headline measures, serialize the payload, and inject it at the template token.

Output

A standalone interactive explorer that works from GitHub Pages or a local file:// view, with no CDN dependency.

This final selection stage is why the DAG reconverges without implying that every computed table becomes a separate panel. The generated page is a presentation of the analysis, not the analysis itself.

Interpretation

What the method can—and cannot—show.

  • Heuristic measurements. Sentence splitting, syllable counting, and passive detection are approximate, but the same rules are applied to every document so comparisons remain consistent.
  • Small z-score baseline. Z-scores use only eight earlier strategic plans. Their directions are useful; their magnitudes are inflated and should not be treated as effect sizes.
  • Comparator matters. SP-2023 is the primary comparator because it is the plan the draft replaces. The eight-plan mean and full prior record answer different questions.
  • Different document status. The 2026 source is a working draft released for public comment, while the earlier record consists largely of finished publications.
  • No inference of motive. Linguistic comparison cannot establish intent. Genre change, deadline pressure, and a committee working without an institutional handoff can produce observable language differences without revealing why they occurred.
