# IACC Linguistic Comparison

**How does the July 2026 IACC Strategic Plan working draft differ from everything the Interagency Autism Coordinating Committee published between 2007 and 2023?** This repository contains a single Jupyter notebook that answers that question quantitatively — style, vocabulary, naming conventions, similarity, text reuse, and 17-year trends — plus all of its precomputed results.

## Run it — no PDFs needed

The extracted, cleaned text of all 61 documents (60 archive publications + the draft) ships in `.pdf_cache/iacc_linguistic/`, keyed by content hash with a `cache_manifest.json`. On a fresh clone the notebook detects the missing PDFs and runs entirely from that cache:

```bash
pip install -r requirements.txt
jupyter notebook iacc_linguistic_comparison.ipynb   # or: jupyter nbconvert --to notebook --execute iacc_linguistic_comparison.ipynb
```

Runtime is a couple of minutes on a laptop. Figures and CSVs are written to `outputs/iacc_linguistic/` and `report.md` is regenerated there.

## Reproduce from source (optional)

To re-derive everything from the original PDFs instead of the cache:

1. Download the archive listed in `iac/IACC_Publications/INDEX.csv` (each row has its `source_url` on iacc.hhs.gov) into the matching folder structure, and place the working-draft PDF at `iac/IACC Strategic Plan Working Draft July 17.pdf`.
2. Delete `.pdf_cache/iacc_linguistic/` (or set `use_cache=False` in the Config cell) and run the notebook.
3. `pymupdf` (in requirements) is the extractor; `pypdf`/`pdfplumber`/`pdftotext` are fallbacks.

The cache is content-addressed: if a PDF you supply differs by one byte from the one the cache was built from, that document is re-extracted and the rest of the cache is still used.

## What the notebook computes

| Section | Contents |
|---|---|
| 1–2 | Corpus inventory; PDF extraction; cleaning (running headers/footers, tables of contents, reference lists removed — verified by citation density) |
| 3 | Style profile per document: readability (Flesch, FK, Fog, SMOG, Coleman–Liau, ARI), lexical diversity (MATTR), passives, modality, hedges/boosters, nominalisation, acronyms |
| 4 | Domain lexicon: person-first vs identity-first naming, ASD vs autism, treatment vs services, causes, equity, governance, modal verbs |
| 5 | Z-scores: where the draft sits against the earlier strategic plans |
| 6 | Keyness (weighted log-odds, Monroe et al. 2008): what the draft over- and under-uses; brand-new and dropped vocabulary |
| 7 | TF-IDF cosine similarity, MDS map, Burrows' Delta stylometry |
| 8 | Text reuse: 8-word-shingle inheritance, per plan and for the draft |
| 9 | Trends 2007–2023 (Spearman) and whether the draft continues or reverses each |
| 10 | The draft section by section: style, novelty, nearest earlier document |
| 11–12 | Export (CSVs, figures, `report.md`); smoke tests of the measurement code |

## Results and interpretation

- `outputs/iacc_linguistic/report.md` — headline numbers, auto-generated by the notebook.
- `outputs/iacc_linguistic/critique_memo.md` — consolidated critique memo: verified findings, plain-language method explanations, interpretation, and caveats.
- `outputs/iacc_linguistic/*.png` — every figure; `*.csv` — every table behind them.

## Caveats

Sentence splitting, syllable counting, and passive detection are heuristic but applied identically to every document, so comparisons are fair even where absolute values are approximate. Z-scores compare against only 8 earlier strategic plans, so their magnitudes are inflated; directions are reliable. Easy-read/at-a-glance editions and documents under 2,000 words are inventoried but excluded from comparisons.

Source archive: [iacc.hhs.gov/publications](https://iacc.hhs.gov/publications/) (downloaded 2026-09-15; see `iac/IACC_Publications/README.md`).
